What the sample contains

A two-file FastAPI + OpenAI Agents app shipped with AIBOM Inspector as a test fixture. It is deliberately vulnerable: a request body is concatenated into an agent's instructions, and that agent can call a tool that runs shell commands. It is scanned offline and never executed.

What is analyzed, and what is not
  • Dependencies: requirements*.txt, pyproject.toml, Pipfile, package.json, go.mod, Cargo.toml, composer.json, Gemfile and more. Package-to-package relations come only from lockfiles that record them (package-lock.json, poetry.lock, uv.lock, Cargo.lock, composer.lock, Gemfile.lock).
  • AI components: models, providers, prompts, tools and agents in Python and JavaScript/TypeScript source (OpenAI, Anthropic, Hugging Face, OpenAI Agents SDK, MCP servers and configs).
  • Agent permissions: evaluated only when the repository has an aibom-identity.yaml that maps agents to IAM policy files.
  • Not analyzed: values chosen at run time, code that is only reachable dynamically, private repositories, and files larger than 2 MB.
Where your data goes
  • The repository is shallow-cloned into a temporary directory on the analysis server and deleted when the analysis ends. Results are not stored on the server.
  • Package names, ecosystems and exact versions are sent to OSV.dev to look up advisories; Hugging Face model and dataset IDs are sent to huggingface.co for license and model-card metadata.
  • Code is read as text: nothing from the repository is executed and model weights are never loaded. Findings come from deterministic rules, not from an AI model.

    Help

    Accepted repositories

    • Public repositories on github.com, gitlab.com, bitbucket.org and codeberg.org, as https://host/owner/repository.
    • Optional: a branch, tag or full commit SHA in the second field.
    • Not accepted: private repositories, GitLab subgroups, links to a file or folder (/tree/…, /blob/…), and other hosts.

    Limits and failures

    • The clone times out after 120 seconds; checkouts over 300 MB or 60,000 files are rejected. Use the CLI on a local checkout for larger repositories.
    • “No analysis backend”: this page is only the interface; set a backend under Advanced.
    • Advisory lookup failures are listed under Analysis limits in the result, never reported as “no vulnerabilities”.

    Command line

    • pip install "aibom[server]", then aibom scan PATH for a local checkout (private code never leaves your machine).
    • aibom diff BASE HEAD --fail-on high fails CI on a new risky path; add --agent-privileges to compare agent permissions.

    Compare changes between two revisions

    Two scans of the same repository are compared on separate questions: did the components change, did a new path appear from untrusted input to a tool an agent can call, and did an agent gain cloud permissions. The component list can stay identical while the other two change.

    Your repository

For CI, run aibom diff with --fail-on high.
